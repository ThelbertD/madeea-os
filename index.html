Run it yourself

Needs Node.js 20+. Takes a few minutes the first time, seconds after that.

# 1 — get the code
git clone https://github.com/ThelbertD/madeea-os.git
cd madeea-os/source

# 2 — install and start
npm install
npm run dev

# 3 — open http://localhost:3737 in Chrome

For free AI with no API key, run the gateway alongside it:

npm install -g omniroute && omniroute   # leave running

Good to know

  1. It runs on your computer. The dashboard binds to localhost, so nobody else on your network can open it.
  2. You bring your own keys. The repo ships placeholders only. Most tabs work without any key; some need their own.
  3. Free models throttle. OmniRoute walks a fallback chain across free providers, so replies occasionally fail — that's normal, and MADEEA-CHANGES.md explains how to switch models.
  4. Use it at your own risk. It's a power tool that runs agents on your machine — see DISCLAIMER.md.
